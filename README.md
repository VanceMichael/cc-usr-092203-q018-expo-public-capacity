# 东博会公众承载

管理公众开放日的分区容量、排队、可达路线和应急疏散。

## 资料约定

`contracts/domain.schema.json` 描述共享资料的字段结构，`fixtures/domain.json` 提供不含真实个人信息的业务样例。读取模块只校验资料边界，不预先实现业务流程。

当前资料反映以下领域事实：

- 公众开放日仅两天，未来空间展区火箭模型、可上手AI商品与东帝汶展馆在不同时段形成客流峰值
- 局部容量由展馆、入口、通道、展项、演示时段和人员能力样例共同决定，仅按总入场人数限流仍可能让单条通道或单个互动点瞬间失控
- 预约、现场排队、无障碍通行、团队访客、未成年人陪同和临时封控共同占用局部容量
- 设备故障、展商暂停演示、突发疏散和路线改道会立即改变可达路径，已进入封控区的人员需要明确引导
- 观众端需要获得真实等待时间和下一可选路线
- 工作人员只能操作其负责区域，指挥席需要从拥挤预警回看计数来源、调整命令和疏散确认
- 科普展示互动不属于零售订单，两类统计必须分开

## 本地校验

运行项目自带测试可确认样例资料能够被读取，领域标识、版本、参与方、事实和约束均保持完整。仓库不保存账号、密钥、连接串或真实身份资料。
